# Playwright Interview Coach

A voice practice page for Playwright + TypeScript interview prep.
Ask a question out loud, see the matching answer, hear it read aloud, and the page listens for the next question.

Live page: https://ramkumar-al.github.io/interview-coach/

The answers are not stored in this repo. On first use, load your own answers JSON file; it is saved only in your browser.

Works in Chrome (Android, desktop), Edge, and Safari (iPhone).
